# TEST_CASES.md

Все тест-кейсы позитивные (happy path). Сервис должен быть запущен на `http://localhost:8080`.

---

## TC-01 - Создание сущности

**Эндпоинт:** `POST /api/create`  
**Тест:** `test_create_entity`

**Предусловия:** сервис запущен и доступен.

**Шаги:**
1. Отправить `POST /api/create` с телом:
   ```json
   {
     "title": "Тестовая сущность",
     "verified": true,
     "important_numbers": [1, 2, 3],
     "addition": {
       "additional_info": "Доп. сведения",
       "additional_number": 42
     }
   }
   ```

**Ожидаемый результат:**
- Статус ответа: `200 OK`
- Тело ответа: строка, содержащая числовой ID созданной сущности (например, `"7"`)

## TC-02 - Получение сущности по ID

**Эндпоинт:** `GET /api/get/{id}`  
**Тест:** `test_get_entity`

**Предусловия:** в БД существует сущность с известным ID (создаётся фикстурой).

**Шаги:**
1. Отправить `GET /api/get/{id}`, где `{id}` - ID из предусловия.

**Ожидаемый результат:**
- Статус ответа: `200 OK`
- Тело ответа десериализуется в объект `EntityResponse`
- Поле `id` объекта совпадает с запрошенным ID
